# Personal Portfolio - Md Abu Zihad

A high-performance, production-ready personal portfolio built entirely with HTML5, CSS3, and Vanilla JavaScript. 
Designed for speed, accessibility, and robust aesthetic appeal without using any heavy frameworks or bundlers.

## Features
- **GSAP & ScrollTrigger** for advanced scroll-based animations.
- **Lenis** smooth scrolling integration.
- **Custom Hardware-accelerated Cursor** with magnetic pulling effects.
- **Responsive Design** across mobile, tablet, and desktop devices.
- **3D Tilt Cards** for skill and project showcases.
- **Zero Dependencies** directly built with pure web technologies.

## Tech Stack
- HTML5 (Semantic Structure)
- CSS3 (CSS Variables, Grid, Flexbox, Animations)
- JavaScript (ES6+ Modules)
- GSAP & Lenis via CDN

## Setup & Deployment
This project is statically built and can be served with any simple static web server (e.g., Live Server, Python HTTP server).

```bash
# Clone the repository
git clone https://github.com/AZtheE1/Portfolio---Md-Abu-Zihad.git

# Navigate to the directory
cd Portfolio---Md-Abu-Zihad

# Serve locally
npx serve .
```

Deployment is automated to GitHub Pages via `.github/workflows/deploy.yml`.
