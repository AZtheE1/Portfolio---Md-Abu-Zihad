### 🚀 Overview
A high-performance, cinematic personal portfolio built with **Pure Vanilla JavaScript**, **GSAP**, and **Lenis**. This project demonstrates how to achieve premium, industry-standard web experiences using zero heavy frameworks, focusing instead on structural integrity, smooth motion, and visual excellence.

**Live Demo:** [azthee1.github.io/Portfolio---Md-Abu-Zihad](https://azthee1.github.io/Portfolio---Md-Abu-Zihad/)

---

### ✨ Key Features

- **🎬 Dynamic Video Engine**: High-responsiveness background video scrubbing synced to scroll progress for a 3D cinematic feel.
- **🌊 Smooth Motion Architecture**: Integrated with **Lenis** for ultra-smooth scrolling across all browsers.
- **🎨 Atmospheric Design**: Deep-space dark mode with glassmorphism overlays and vibrant gradient highlights.
- **✨ Magnetic Interactivity**: custom hardware-accelerated cursor with magnetic pulling effects on buttons and links.
- **🎭 GSAP Scroll Orchestration**: Perfectly timed reveal animations and parallax effects as you navigate the page.
- **📱 Fluid Responsiveness**: Fully optimized for mobile, tablet, and desktop with adaptive video fallbacks.
